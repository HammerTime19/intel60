AMD Turin CPU flaws leak VM data cross-process

Google Cloud identified three CPU side-channel flaws in AMD Turin processors that allow attackers with code on the same processor core to infer data from other processes or the kernel within a VM. Google has mitigated inter-VM and VM-to-host attacks. Customers must apply guest OS patches and perform stop-start operations to protect individual VMs from intra-process attacks.
